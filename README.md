# Nabih AI

**Nabih AI** is a modern Android conversational AI assistant supporting multi-model AI interactions, voice, image, and document capabilities in both Arabic and English.

## Features

- **Multi-Model AI**: Seamlessly switch between leading AI models (Gemini, Claude, GPT-4o, and Nabih Ultra).
- **Full Bilingual Support**: Native Arabic and English interface with dynamic RTL/LTR layout mirroring.
- **Voice & Attachments**: Voice notes preview/recording, image uploads, and document parsing.
- **Local Persistence**: Offline-first chat history, folders, and search backed by Room Database.
- **Security & Privacy**: Encrypted local storage for custom API keys and preferences.

## Tech Stack

- **Language**: Kotlin
- **UI**: Jetpack Compose (Material Design 3)
- **Architecture**: MVVM
- **Database**: Room Database
- **Backend & Auth**: Firebase Auth, Firebase AI Logic, Retrofit
